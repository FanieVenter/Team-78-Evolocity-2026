Note that there is a huge gap as I only started logging the progress since 2026/05/26 this is as I only heard of Hackclub then. 
## 2026-01-20 - Started Designing Gearbox
- Started Gearbox Design after watching a video about how gearboxes for dragsters are designed and decided to take some inspiration
## 2026-05-29 - Initial Setup & Documentation
- Created readme describing the planetary gearbox concept
- 2-gear planetary gearbox designed in FreeCAD
- Uses friction engagement to switch between a chosen ratio and direct drive
- Cams change position of the ring-gear and contact point to shift gears
- Components modelled: sun gear, planet gears (×4), ring gear, input shaft, shifter, planet carrier, contact point

## 2026-05-29 - Project Structure
