# Evolocity Telemetry — KiCad PCB

Custom PCB designed in **KiCad** for the Team 78 Evolocity 2026 go kart telemetry system.

## Files

- `evolocity-telemetry-main.kicad_pcb` — PCB layout
- `evolocity-telemetry-main.kicad_sch` — Main schematic
- `evolocity-telemetry-main.kicad_pro` — KiCad project
- `power-supply.kicad_sch` — Power supply schematic
- `evolocity-telemetry-main-backups/` — Project backups

## Features

- Onboard telemetry data logging
- Dedicated power supply section
- Designed for the Evolocity 2026 competition requirements
