# Team 78 — Evolocity 2026 Go Kart

[![Marvle3d](https://img.shields.io/badge/Title%20Sponsor-Marvle3d-ff6b35?style=for-the-badge)](https://marvle3d.co.nz)

**Thanks to [Marvle3d](https://marvle3d.co.nz)** — they've been supplying us with 3D printing filament for the kart body. Shout out to them!

This is Team 78's project for Evolocity 2026. We're building an electric go kart and this repo contains all the design files, CAD models, and electronics schematics.

## What we've got

| Project | What it is |
|---------|-----------|
| [Body](Evolocity%202026/Body/) | The body and chassis — designed in FreeCAD and Blender, then 3D printed |
| [Gearbox](Evolocity%202026/Gearbox/) | A custom 2-speed planetary gearbox designed in FreeCAD |
| [Telemetry](Evolocity%202026/evolocity-telemetry-main/) | PCB for telemetry sensors and power distribution, made in KiCad |

## How to use this

**If you want to see the designs:**
- Check the `.stl` files with a 3D viewer
- Look at the rendered images in each folder

**If you want to modify the designs:**
1. Download [FreeCAD](https://www.freecadweb.org/) (it's free and open source)
2. Open the `.FCStd` files
3. Edit whatever you need

**If you're going to 3D print it:**
- Use the `.stl` files in your slicing software
- We printed everything on FDM printers using Marvle3d filament
- Some parts are pretty large so you might need to print them in sections
