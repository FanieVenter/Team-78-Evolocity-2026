# Team 78 — Evolocity 2026 Go Kart

[![Marvle3d](https://img.shields.io/badge/Title%20Sponsor-Marvle3d-ff6b35?style=for-the-badge)](https://marvle3d.co.nz)

**Presented by Marvle3d** — This project is proudly sponsored by **Marvle3d**, who are providing 3D printing filament for the go kart body.

A custom electric go kart built for the Evolocity 2026 competition. This repository contains all design files, CAD models, and electronics schematics for the kart.

## Sub-Projects

| Project | Description |
|---------|-------------|
| [Body](Evolocity%202026/Body/) | 3D-printed body and chassis design (FreeCAD, Blender) |
| [Gearbox](Evolocity%202026/Gearbox/) | Custom 2-speed planetary gearbox (FreeCAD) |
| [Telemetry](Evolocity%202026/evolocity-telemetry-main/) | KiCad PCB design for telemetry and power supply |
